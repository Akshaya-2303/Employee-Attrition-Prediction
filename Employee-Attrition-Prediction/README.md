# Employee Attrition Prediction System

A machine learning project that predicts whether an employee is likely to leave a company, using workplace, performance and demographic data. It covers the full ML pipeline: data generation, preprocessing, EDA, model training and tuning, evaluation, and a prediction interface (console + Streamlit).

## Technologies Used
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Joblib, Streamlit

## Dataset Description
`data/employee_data.csv` is a synthetic HR dataset of 1,500 employees (generated by `src/generate_data.py`, ~13% attrition, ~2% missing values on purpose).

| Column | Description |
|---|---|
| EmployeeID | Unique identifier (not used for training) |
| Age | Employee's age |
| Department | Sales / Engineering / HR / Marketing / Finance |
| MonthlyIncome | Salary in ₹ |
| YearsAtCompany | Tenure in years |
| JobSatisfaction, WorkLifeBalance, PerformanceRating | Scores 1–5 |
| OverTime | Yes / No |
| DistanceFromHome | Distance in km |
| Attrition | **Target** – Yes / No |

## How It Works
- **Missing values:** median (numbers) / most frequent (text) imputation.
- **Encoding & scaling:** One-Hot Encoding for Department and OverTime; StandardScaler for numbers.
- **Class imbalance:** `class_weight="balanced"` gives more importance to the minority class (employees who leave).
- **No data leakage:** the train/test split happens first, and all preprocessing lives inside a scikit-learn `Pipeline`, so it is learned from training data only (also inside each cross-validation fold).
- **Tuning:** `GridSearchCV` with 5-fold stratified CV, optimising ROC-AUC.

## Model Performance Comparison (20% test set)

| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC |

| **Logistic Regression** | 0.747 | 0.313 | 0.795 | 0.449 | **0.853** |
| Random Forest | 0.803 | 0.361 | 0.667 | 0.468 | 0.807 |

**Best model: Logistic Regression.** It has the highest ROC-AUC (best at ranking likely leavers) and the highest recall (catches ~80% of employees who actually leave). In HR, missing a person who is about to leave is costlier than a false alarm, so recall matters most. It is also simple and easy to explain. Accuracy alone is misleading here, because always predicting "No" would already give ~87%.

## Key Insights from EDA
- Overall attrition rate is **13.1%**.
- **Overtime** is the strongest factor: 22.2% of overtime employees leave vs 9.3% of others.
- **Job satisfaction:** attrition falls from 24.8% (score 1) to 6.7% (score 5).
- **Department:** Sales (16.7%) and HR (15.3%) are highest; Finance is lowest (10.3%).
- Employees with **higher income, longer tenure and higher age** are less likely to leave (correlations ≈ -0.26).
- Top model factors: job satisfaction, monthly income, overtime, work-life balance.
- Note: the data is synthetic, so these patterns are illustrative rather than real-world findings.

## Error Handling
Inputs are validated (negative age/income, invalid department, scores outside 1–5, impossible tenure, non-numeric values). Missing dataset or model files and corrupted model files show clear messages instead of crashing.
